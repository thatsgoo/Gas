# 氛围白模沙盒 — 设计规范（DESIGN.md）

> 依据项目本地 `.agents/skills/refactoring-ui`（Workflow A）生成，全部 13 组昼/夜文字对比度均通过 WCAG AA（≥ 4.5:1）。

## 1. 个性与气质决策
- **定位**：建筑工作室暖纸感（白天） ⇄ 静谧靛蓝夜色（雨夜），服务于**零 UI 赛璐璐 3D 画布**。
- **原则**：画布永远是唯一视觉主角，一切浮层胶囊通过弱化边框、柔和抬升影（光自上方）退居二线。
- **字重限制（Law 6）**：仅使用 `500`（正文/常规控件）与 `600`（选中态/关键数值/标题），绝不低于 `400`。
- **三层文字色**：主文本（`paper-900` / `night-100`）、次文本（`paper-700` / `night-200`）、辅助读数（`paper-600` / `night-300`）。

## 2. 动作层级金字塔（Law 8）
- **一级主操作（每屏仅 1 个）**：导出独立 HTML / 高清展板图（主色 `primary-500` 实心按钮）。
- **二级状态开关**：自动吸附、XYZ 锁定、双视角切换、天气切换（采用翻转对比的浅底深字胶囊，并配合图标+边框变化，不单靠颜色表达）。
- **三级辅助动作**：复制、撤销重做、删除、重置底座（无底色轻幽灵按钮；删除绝不用刺眼大红实心块）。

## 3. 间距与圆角系统（Law 3 & 5）
- **间距阶梯**：`4px` / `8px` / `12px` / `16px` / `24px`；严守**组间间距（`12px–16px`）> 组内间距（`4px–8px`）**。
- **圆角**：按钮与输入框 `6px`（`sm`），悬浮胶囊/抽屉 `16px`（`lg`），状态徽章 `9999px`（`full`）。
- **边框宽度**：仅 `1px`（柔和分隔与顶部高光边缘）与 `2px`（选中聚焦环）。
